\*\*스캐폴딩(Scaffolding)\*\*은 소프트웨어 개발에서 프로젝트를 개발하기 위해 필요한 기본 구조와 초기 코드를 자동으로 생성하는 작업을 의미합니다.

코딩 에이전트(Claude Code, Codex 등)가 자주 사용하는 용어입니다.

## 1. 쉽게 이해하기

건물을 짓는다고 생각해 보겠습니다.

- 스캐폴드(Scaffold): 건축할 때 사용하는 비계(임시 작업 구조물)
- 스캐폴딩(Scaffolding): 개발자가 본격적으로 코드를 작성할 수 있도록 프로젝트의 기본 뼈대를 만드는 작업

예를 들어 코딩 에이전트에게 다음과 같이 요청했다고 가정하겠습니다.

> Next.js와 TypeScript를 사용해서 로그인 기능이 있는 웹서비스를 만들어줘.

에이전트가 먼저 다음과 같은 프로젝트 구조를 생성할 수 있습니다.

스캐폴딩 결과 예시

Next.js 프로젝트

디렉터리, 설정 파일, 기본 컴포넌트 등이 자동 생성된 상태

이 과정이 바로 스캐폴딩입니다.

프로젝트의 기본 구조가 준비되었기 때문에 개발자는 로그인 로직, 데이터베이스 연동, 사용자 인증 등의 실제 기능 구현에 집중할 수 있습니다.

## 2. 스캐폴딩과 실제 구현의 차이

| 구분   | 스캐폴딩           | 실제 구현          |
| ---- | -------------- | -------------- |
| 목적   | 개발 기반 마련       | 기능 완성          |
| 디렉터리 | 폴더 구조 생성       | 필요한 구조 확장      |
| 코드   | 기본 파일 및 템플릿 생성 | 실제 비즈니스 로직 작성  |
| 설정   | 패키지와 환경 설정     | 운영 환경에 맞게 조정   |
| 결과   | 개발 시작 가능한 상태   | 요구 기능이 동작하는 상태 |

다만 스캐폴딩의 범위는 도구에 따라 다릅니다. 일부는 실행 가능한 예제 코드, 기본 테스트, CI 설정까지 생성합니다.

## 3. 코딩 에이전트에서 자주 등장하는 표현

① "Scaffold the project"

프로젝트의 초기 구조를 만들어라는 뜻입니다.

② "Scaffold a REST API"

API 엔드포인트, 라우터, 컨트롤러, 스키마 등 기본 코드를 생성하라는 뜻입니다. 실제 데이터 처리 로직은 아직 미완성일 수 있습니다.

③ "Scaffold the authentication module"

인증 관련 폴더, 인터페이스, 미들웨어, 기본 함수 등을 만들어라는 뜻입니다. 인증 시스템을 완전히 구현하라는 뜻과는 다릅니다.

④ "Use the existing scaffold"

이미 만들어진 기본 구조를 재사용하라는 뜻입니다.

## 4. 스캐폴딩과 보일러플레이트의 차이

함께 알아두면 좋은 용어가 \*\*보일러플레이트(Boilerplate)\*\*입니다.

- 스캐폴딩: 기본 구조와 코드를 생성하는 작업 또는 과정
- 보일러플레이트: 여러 프로젝트에서 반복적으로 사용하는 기본 코드나 템플릿

예를 들어 `create-next-app`으로 프로젝트를 생성하는 행위는 스캐폴딩이고, 생성된 기본 설정 및 템플릿 코드는 보일러플레이트라고 볼 수 있습니다.

### 코딩 에이전트에서 특히 주의할 점

에이전트가 "스캐폴딩 완료"라고 보고했다면 기능 구현이 완료되었다는 의미는 아닙니다.

예를 들어 다음 두 프롬프트는 결과가 크게 달라질 수 있습니다.

- `Scaffold a KMS service` → KMS 서비스의 기본 구조와 인터페이스 생성
- `Implement a working KMS service` → 실제 키 생성·암호화·복호화·권한 검증 등의 기능 구현 요청

따라서 코딩 에이전트에게 작업을 맡길 때는 \*\*Scaffold(구조 생성), Implement(기능 구현), Test(검증)\*\*를 구분해서 이해하는 것이 좋습니다.
