## 미확인·충돌

- 4-eyes 와 dual control 의 경계는 출처마다 다르고, 일부 자료는 두 용어를 혼용한다. 본문의 구분은 PCI 정의와 NIST 정의를 비교한 해석이다.
- NIST 는 4-eyes 원칙 자체를 정의하지 않는다. 직무 분리와 두 사람 규칙만 확인했다.
- GitHub 브랜치 보호의 설정 항목 이름과 에이전트 도구의 구현은 조사하지 않았다.
