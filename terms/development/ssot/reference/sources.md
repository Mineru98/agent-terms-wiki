## 미확인·충돌

- A 등급 출처는 찾지 못했다. SSOT 는 표준이 정의한 용어가 아니어서 B 등급 1곳과 C 등급 자료로만 확인했다.
- SSOT 를 중앙 저장소로 보는 자료(Guru 등)와 항목별 소유 규칙으로 보는 자료(SIIT 등)가 충돌한다.
- "정본(canonical source)"을 직접 정의한 출처는 찾지 못했다. 본문의 구분은 미확인이다.
- 코딩 에이전트 지시 파일에 SSOT 를 적용하는 설명은 출처가 없는 해석이다.
- 위 사유로 status 는 draft 가 맞다.
