## 미확인·충돌

- PPV 라는 별칭이 정밀도와 같다는 점은 출처 페이지에서 직접 확인하지 못했고 일반 지식에 기반한다. 미확인.
- 측정 분야 정밀도와의 구분은 A 출처로 확인하지 못했다. 미확인.
- 충돌하는 정의는 발견하지 못했다.
- 본문의 80/20 예시는 작성자가 만든 계산 예이다.
