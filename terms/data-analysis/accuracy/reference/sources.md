## 미확인·충돌

- 정확도 정의에 대한 표준 교재는 열어 보지 못했다. A 출처 1곳(scikit-learn)과 C 출처 1곳만 확인되어 status 는 draft 이다.
- 1,000개 표본 예시는 작성자가 만든 계산 예이며 출처의 수치가 아니다.
- 정확도 역설이라는 용어의 출처는 확인하지 못했다. 미확인.
