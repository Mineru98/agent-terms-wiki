# 정확도 (Accuracy)

> 전체 예측 중 맞힌 예측의 비율.

## 요약

- 정확도는 (TP + TN) / (TP + TN + FP + FN) 으로 계산한다.
- 값이 직관적이어서 가장 먼저 쓰이지만, 클래스 불균형이 크면 모델이 쓸모없어도 높게 나온다.
- 불균형 데이터에서는 [정밀도](../precision/README.md), [재현율](../recall/README.md), [F1 점수](../f1-score/README.md), 균형 정확도(balanced accuracy)를 함께 본다.
- [데이터 누수](../data-leakage/README.md)가 있으면 정확도가 실제보다 높게 측정된다.

## 왜 필요한가

분류 모델이 얼마나 맞히는지를 하나의 숫자로 요약할 방법이 필요하다. 정확도는 계산과 해석이 쉬워 모델을 처음 비교할 때 기준선 역할을 한다.

## 어떻게 동작하나

혼동 행렬(confusion matrix)의 네 칸으로 계산한다. TP 는 참 양성(true positive), TN 은 참 음성, FP 는 거짓 양성, FN 은 거짓 음성이다.

```
accuracy = (TP + TN) / (TP + TN + FP + FN)
```

scikit-learn 의 `accuracy_score` 는 예측이 정답과 같은 표본의 비율을 반환한다. 다중 레이블에서는 한 표본의 레이블 집합이 정확히 일치할 때만 1 로 세는 부분집합 정확도(subset accuracy)를 반환한다.

## 예시

양성이 10개뿐인 1,000개 표본에서 모든 표본을 음성으로 예측하는 모델을 생각한다.

```
TP = 0, FP = 0, FN = 10, TN = 990
accuracy = (0 + 990) / 1000 = 0.99
recall   = 0 / (0 + 10)      = 0
```

정확도는 99% 이지만 양성을 하나도 찾지 못한다. 위키백과의 예도 같은 구조로, 음성 95개와 양성 5개에서 전부 음성으로 답하면 정확도는 95% 이고 양성 정밀도는 0% 이며 균형 정확도는 0.5 이다.

다른 모델이 TP = 40, FP = 10, FN = 60, TN = 890 이면 정확도는 930 / 1000 = 0.93 으로 오히려 낮다. 그러나 이 모델은 양성의 40% 를 찾는다. 정확도만 보면 쓸모없는 모델이 더 좋아 보인다.

## 흔한 오해

- **정확도가 높으면 좋은 모델이라고 볼 수 없다.** 다수 클래스 비율이 높을수록 아무것도 학습하지 않은 모델도 높은 값을 얻는다. 이를 정확도 역설(accuracy paradox)이라 부른다.
- **정확도는 유병률(prevalence)에 따라 달라진다.** 위키백과에 따르면 정밀도 90%, 재현율 50% 인 방법의 정확도는 유병률 30% 에서 약 83%, 90% 에서 50% 이다.
- **균형 정확도는 다르다.** scikit-learn 은 균형 정확도를 클래스별 재현율의 평균으로 정의한다. 이진 분류에서는 (재현율 + 특이도) / 2 이다.
- **정확도 평가가 높다고 일반화가 보장되지 않는다.** 학습 정보가 평가에 섞이면 수치가 부풀려진다. scikit-learn 문서는 무작위 특징 1만 개와 무작위 레이블에서 분할 전에 특징을 선택하면 정확도가 약 0.76 까지 나오지만, 분할 후 선택하면 0.5 근처라고 보여 준다.

## 관련 용어

- 비교·인접 용어 (순서 없음)
  - [precision](../precision/README.md): 양성 예측 중 맞은 비율. 정확도가 가리는 거짓 양성을 본다.
  - [recall](../recall/README.md): 실제 양성 중 찾은 비율. 정확도가 가리는 거짓 음성을 본다.
  - [f1-score](../f1-score/README.md): 정밀도와 재현율을 합친 지표로 불균형 데이터에 쓴다.
  - [data-leakage](../data-leakage/README.md): 정확도를 실제보다 높게 만드는 원인.
  - [reproducibility](../reproducibility/README.md): 정확도 비교가 의미 있으려면 분할과 시드가 재현되어야 한다.
