## 미확인·충돌

- OWASP 페이지의 "데이터와 지시의 분리"는 "신뢰할 수 없는 외부 콘텐츠를 분리하고 표시한다"는 항목으로 확인했다. 모델 수준에서 완전한 분리가 가능하다는 근거는 없다.
- Greshake et al. 은 원문 본문이 아니라 검색 요약으로 확인했다.
- 코딩 에이전트 제품별 방어 기능은 조사하지 않았다.
- 충돌하는 출처는 발견하지 못했다.
