# 온도 (Temperature, 샘플링 온도)

> 언어 모델이 다음 토큰을 고를 때 주입되는 무작위성의 정도를 조절하는 샘플링 파라미터.

## 요약

- Anthropic Messages API 문서는 temperature 를 "응답에 주입되는 무작위성의 양"으로 설명하고, 기본값 1.0, 범위 0.0에서 1.0이라고 밝힌다.
- 같은 문서는 분석적이거나 객관식인 작업에는 0.0에 가깝게, 창작이나 생성 작업에는 1.0에 가깝게 쓰라고 안내한다.
- 일반적인 설명에서는 소프트맥스(softmax) 확률 분포를 낮은 온도에서 날카롭게, 높은 온도에서 평탄하게 만든다고 한다. 이 수식 수준의 설명은 이번 조사에서 공식 문서로 확인하지 못했다(미확인, 기억 기반).
- 온도를 0.0으로 설정해도 결과가 완전히 결정적이지는 않다고 Anthropic 문서가 명시한다.
- 최신 Anthropic 모델에서는 이 파라미터 설정이 제한된다. 아래 "흔한 오해"를 참고한다.

## 왜 필요한가

같은 프롬프트에 매번 같은 답이 나오면 창작이나 아이디어 다양화에 불리하고, 매번 달라지면 분류나 추출처럼 일관성이 필요한 작업에 불리하다. 온도는 이 둘 사이의 균형을 호출자가 조절하게 해 준다.

## 어떻게 동작하나

모델은 다음 토큰 후보마다 점수를 내고, 이를 확률 분포로 바꾼 뒤 그 분포에서 토큰을 뽑는다. 온도는 이 뽑기의 무작위성을 조절한다. 일반적 설명은 다음과 같다(미확인, 기억 기반).

| 온도 | 분포 모양 | 결과 경향 |
| --- | --- | --- |
| 낮음(0에 가까움) | 날카로움: 확률이 높은 토큰에 집중 | 예측 가능, 반복적 |
| 높음 | 평탄함: 낮은 확률 토큰도 선택 가능 | 다양함, 예측 어려움 |

공식 문서에서 확인된 범위는 위 요약의 기본값, 범위, 사용 권고, 비결정성 문구까지다.

## 예시

```python
response = client.messages.create(
    model="<모델 이름>",
    max_tokens=1024,
    temperature=0.0,   # 분류, 추출처럼 일관성이 필요한 작업
    messages=[{"role": "user", "content": "다음 문장의 감정을 긍정/부정으로 분류하라: ..."}],
)
```

## 에이전트 맥락

에이전트가 도구 인자를 만들거나 코드를 수정할 때는 보통 낮은 온도가 선호된다고 알려져 있으나, 이 권고를 뒷받침하는 공식 문서는 이번 조사에서 확인하지 못했다(미확인). 호출하는 모델이 온도 설정을 받는지부터 문서로 확인해야 한다.

## 흔한 오해

- **온도 0은 항상 같은 결과를 보장한다.** 틀린 설명이다. Anthropic 문서는 "temperature 가 0.0이어도 결과가 완전히 결정적이지는 않다"고 밝힌다. 그 원인은 이번 조사에서 공식 문서로 확인하지 못했다(미확인). OpenAI 문서에서는 같은 취지의 문구를 확인하지 못했다.
- **모든 모델에서 온도를 설정할 수 있다.** 같은 Anthropic 문서는 temperature 가 지원 중단(deprecated)이며, Claude Opus 4.6 이후에 출시된 모델은 설정을 지원하지 않는다고 밝힌다. 이 경우 1.0만 하위 호환을 위해 받아들여지고 다른 값은 400 오류로 거부된다.
- **온도와 top-p 는 같은 것이다.** 둘 다 무작위성에 관여하지만 방식이 다르다. 아래 비교를 참고한다.

### top-p 와의 차이

top-p 는 핵 샘플링(nucleus sampling)이다. Anthropic 문서는 토큰을 확률 내림차순으로 정렬해 누적 확률을 계산하고, 그 값이 `top_p` 에 도달하면 나머지를 자르는 방식으로 설명한다. 즉 온도는 분포의 모양을 조절하는 쪽이고, top-p 는 후보 집합의 범위를 자르는 쪽이다(이 대비는 두 문서 설명을 종합한 정리다). 두 값을 함께 바꾸는 것에 대한 권고는 OpenAI 공식 문서 원문을 열지 못해 미확인이다. 2차 자료는 둘 중 하나만 바꾸라는 권고가 있다고 전한다.
